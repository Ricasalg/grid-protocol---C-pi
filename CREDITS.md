# CREDITS

GRID PROTOCOL is an original work. It takes inspiration from the atmosphere and
visual language of *TRON: Legacy*, but the world, characters, systems, names,
dialogue and music in this project are original and were written or generated
for it.

No scene, asset, line of dialogue, character design or piece of music from the
film or from Disney is reproduced here.

---

## Original content in this project

Everything below is either written for this project or generated by code at
runtime. Nothing here is a capture, a rip, or a copy of existing material.

| Category | Origin |
|---|---|
| World, lore, characters | Original. Written for this project. |
| The ISO **QUELL** | Original character. Name, light pattern, voice and secret invented for this project. |
| Dialogue and fragments | Original. Stored as data in `src/iso/iso.ts` and `src/data/network.json`. |
| Sector and node definitions | Original. `src/data/network.json`. |
| All geometry | Generated procedurally at runtime. `InstancedMesh`, `BufferGeometry`, `EdgesGeometry`. |
| All textures / materials | Procedural `ShaderMaterial` GLSL. No image files. |
| All audio | Generated by the Web Audio API at runtime. No audio files ship. |
| All shaders | Written for this project. See `src/render/materials.ts`. |

There are no `.glb`, `.fbx`, `.obj`, `.blend`, `.max`, `.png`, `.jpg`, `.ktx2`
or audio assets in this repository. This is a deliberate outcome, not an
omission: §6.6 of the design prioritises procedural content so that the project
carries no binary payload it does not need.

## Audio

The music and sound in GRID PROTOCOL are **synthesised in the browser** by
`src/audio/engine.ts` using oscillators, filters and a feedback-delay reverb.
No audio recording is bundled, sampled or extracted from any reference
material.

The project ships with no audio files at all. The audio system is deliberately
modular — each area has its own parameter set (`AREAS` in `src/audio/engine.ts`)
that crossfades as you move between them — so licensed or commissioned music
can be substituted later without touching gameplay code.

## Security posture

GRID PROTOCOL runs entirely in the browser and cannot affect the host system.
Specifically, the project:

- does **not** read, write, move or delete any file on the user's machine;
- does **not** access the user's documents, folders, or any local path;
- does **not** execute system programs or shell commands;
- does **not** modify Windows settings, the registry, or any environment;
- does **not** install anything and requests no dangerous permissions;
- does **not** use the File System Access API, and requests no file picker;
- performs **no network requests** of any kind at runtime — no CDN, no font
  service, no analytics, no telemetry.

Every terminal, file, log and "network connection" in the game is a visual
representation with fictional content, drawn inside the WebGL canvas.

The only thing that persists is the player's progress, stored in `localStorage`
under the keys `grid-protocol.save.v1` and `grid-protocol.settings.v1`. Players
can delete it at any time from **Settings → DELETE SAVE**, which clears those
keys and reloads the experience.
